```typescript
// 第 68-94 行：loading 状态管理和 useEffect
const [loading, setLoading] = useState(false)
const [, setTick] = useState(0)

useEffect(() => {
  if (isSubjectRegistered(subject.id)) {
    setLoading(false)
    return
  }
  if (!isSubjectLoadable(subject.id)) {
    setLoading(false)
    return
  }

  setLoading(true)
  let cancelled = false

  loadSubjectData(subject.id)?.then(() => {
    if (!cancelled) {
      setLoading(false)
      setTick(t => t + 1)  // 强制重渲染
    }
  }).catch(() => {
    if (!cancelled) setLoading(false)
  })

  return () => { cancelled = true }
}, [subject.id])
```

## ❌ 常见问题排查

### 问题 1：一直显示 loading

**检查方法**：
1. 按 F12 打开开发者工具
2. 查看 Console 是否有错误
3. 查看 Network 标签，检查数据加载请求

**可能原因**：
- 数据文件加载失败
- 网络问题
- 代码逻辑错误

**解决方法**：
```bash
# 重启开发服务器
npm run dev

# 检查类型错误
npx tsc --noEmit

# 重新构建
npm run build
```

### 问题 2：模块显示不全

**可能原因**：
- 数据未完全加载
- `getSubjectData()` 返回 `undefined`
- 异步加载未完成就读取数据

**解决方法**：
- 确认 `SubjectModuleGrid` 组件已添加 loading 状态
- 确认 `useEffect` 正确触发数据加载
- 确认 `setTick(t => t + 1)` 强制重渲染

### 问题 3：Badge 数字为 0

**可能原因**：
- 数据加载完成后未触发重渲染
- `modelCount`、`paradigmCount` 等变量读取时机错误

**解决方法**：
- 检查 `setTick(t => t + 1)` 是否在 `loadSubjectData` 完成后调用
- 检查 `subjectData` 是否在 loading 完成后重新读取
