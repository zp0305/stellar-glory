### 问题 3：Badge 数字显示为 0

**可能原因**：
- `getSubjectData()` 返回 `undefined`
- 异步加载未完成就读取数据

**解决方法**：
- 确认 `SubjectModuleGrid` 组件已添加 loading 状态处理
- 确认 `useEffect` 正确触发数据加载
- 确认 `setTick(t => t + 1)` 强制重渲染

## 📝 修复内容总结

### 修改文件

**`src/sections/SubjectGuidePage.tsx`**

#### 1. 添加异步加载相关导入
```typescript
import { Spinner } from '@/components/ui/spinner'
import { getSubjectData, isSubjectRegistered } from '@/data/registry'
import { loadSubjectData, isSubjectLoadable } from '@/data/loaders'
import { useState, useEffect } from 'react'
```

#### 2. 添加 loading 状态管理
```typescript
const [loading, setLoading] = useState(false)
const [, setTick] = useState(0)
```

#### 3. 添加 useEffect 触发数据加载
```typescript
useEffect(() => {
  if (isSubjectRegistered(subject.id)) {
    setLoading(false)
    return
  }
  if (!isSubjectLoadable(subject.id)) {
    setLoading(false)
    return
  }

  setLoading(true)
  let cancelled = false

  loadSubjectData(subject.id)?.then(() => {
    if (!cancelled) {
      setLoading(false)
      setTick(t => t + 1)
    }
  }).catch(() => {
    if (!cancelled) setLoading(false)
  })

  return () => { cancelled = true }
}, [subject.id])
```

#### 4. 添加 loading UI
```typescript
if (loading) {
  return (
    <AppLayout showSubjectNav>
      <div className="flex items-center justify-center h-64 gap-3">
        <Spinner className="w-6 h-6 text-primary" />
        <span className="text-muted-foreground">{subject.name}学科数据加载中...</span>
      </div>
    </AppLayout>
  )
}
```

#### 5. 修复类型错误
